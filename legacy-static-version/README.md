# Legacy Static HTML/CSS/JS Version

This folder contains the original standalone static implementation of **Krishi Sansar**:
- `index.html`: Static web page
- `style.css`: Original stylesheet
- `script.js`: Vanilla JavaScript engine
- `images/`: Local image assets

To view this version offline, you can directly double-click `index.html` in any web browser.

The main application of this project is the modern **React.js** app located in the root directory.
